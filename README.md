# 🚆 IRCTC Core Java Console Application

A console-based Railway Reservation System developed using **Core Java**. This project simulates the basic functionalities of the IRCTC platform such as user registration, authentication, train search, ticket booking, ticket cancellation, and booking management. It is built without a database and uses Java Collections for in-memory data storage.

---

## 📌 Project Overview

This project was developed to strengthen Core Java concepts by implementing a real-world application. The system allows users to register, log in, search available trains, book tickets, cancel booked tickets, and manage their bookings through a menu-driven console interface.

The application follows Object-Oriented Programming (OOP) principles and uses Java Collections to manage users, trains, and ticket information without relying on a database.

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Vedantji3/IRCTC-Core-Java.git
```

2. Open the project in IntelliJ IDEA.

3. Run the `IRCTCAPP.java` file.

4. Follow the console menu to use the application.
